// => { fpOutDocx: '…', sizeDocx: 39856, sizeHtml: 12345, ms: 8342 }

(async) addDocxToc(fpDocx, optopt) → {Promise}

Description:

  • 於docx添加章節目錄、圖目錄、表目錄並重編頁碼

    先以純結構處理準備內容(見docxToc.mjs之prepDocxToc：圖名表名編號改SEQ欄位、標題粗體改由樣式提供、插入目錄欄位、分節與頁碼)，再以本機Microsoft Word更新欄位(目錄內容與頁碼只有Word能算)，最後逐項核對目錄項目、連結落點、頁碼與分節，全部相符才覆寫原檔。故僅能於已安裝Word之Windows執行，Word之調用與轉檔共用同一佇列。

    頁碼：第1個標題前有內容者視為封面，封面無頁碼；前置章節與目錄為大寫羅馬數字(I起)；正文自1起。無封面者不另建封面頁。

    標題以段落之大綱階層判斷，第1個標題即視為正文之始(前置章節除外)：Markdown以單一#為文件標題、##為章者，文件標題會列為目錄第1層且正文自其起算；欲置於封面請以非標題之段落撰寫(如

    )。

    Word更新以cscript執行updateDocxToc.vbs(VBScript)：微軟已公告VBScript將轉為選用功能並於日後移除，屆時須另行啟用或改以其他方式調用Word。逾時被終止時，經COM啟動之WINWORD行程可能殘留，須人工確認後結束。

    文件無標題段落時不處理並於回傳之skip說明原因；前提不符或核對不符時reject，原檔不變。

(async) cvMdToDocx(fpInMd, fpOutDocx, optopt) → {Promise}

Description:

  • Markdown檔轉Docx檔

    內部流程為md -> html -> docx。docx階段係調用本機Microsoft Word(win32com)，故僅能於已安裝Word之Windows執行，且同時間僅一份轉檔作業(內部佇列自動排隊)。

    轉檔器htmlToDocx.exe之定位與補齊由w-html2docx負責：其以當前工作目錄(cwd)查找，缺檔(如npm封鎖安裝腳本致postinstall未執行)時於轉檔當下自動下載，故須於含node_modules/w-html2docx之專案根執行，且首次轉檔須可連網。

    w-html2docx(≥1.0.29)於轉檔器失敗(Word未安裝、模板無法開啟、另存失敗等)時以離開碼1 reject並帶轉檔器回報之原因，resolve前亦自行確認docx已產生；本函數將其訊息加上前綴原樣傳出，並再以產物實體檔之存在與大小把關一次，不會回報假成功。
